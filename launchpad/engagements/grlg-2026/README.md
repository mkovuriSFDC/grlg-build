The shared workspace for an AI-native delivery pod — Salesforce metadata, decision log, sprint notes, AI delivery skills. Seeded by the [`quantum-leap-launchpad`](https://git.soma.salesforce.com/dgerow/quantum-leap-launchpad) plugin via `/ql-init-engagement`. One update path: `/ql-resync` (Claude Code, with the plugin installed) refreshes the vendored `ql-*` **skills** together with the **engine scripts** they call, plus the **`AGENTS.md` conventions and CI/PR scaffold**.

## Setup

Prereq: **Node ≥ 22.20** (https://nodejs.org or `nvm install 22`).

Open the folder in your agent harness (Claude Code, Cursor, Codex, opencode, …) and run `/ql-setup`. It installs the tooling (the `sf` CLI and the build toolkits) and wires the MCP servers in one pass: Atlassian for Jira reporting, and Salesforce Docs for doc grounding.

(If you just want the installs without an agent, `node launchpad/scripts/setup.mjs` covers the tooling, but you'll still need `/ql-setup` for the MCP config.)

Scope comes from the tied Scopezilla source above, read in place and never copied; re-run `/ql-ingest-scopezilla` to reconcile a fresh upstream run. New asks or notes become intents via `/ql-capture-intent`.

Then start building: `/ql-start-intent INT-001`. Not sure what's next at any point? `/ql-guide`.
